# Protocol: Small Task

Use for a local documentation update affecting one area or one small cluster of docs.

## Flow

```text
Route-lite → Mini Plan → Apply → Validate-lite → Report
```

## Mini Plan

Include:

- target paths
- evidence sources
- acceptance criteria
- whether delegation is used

## Escalation

Escalate to M if:

- multiple domains are affected
- new leaf docs appear necessary
- index content sink risk is detected
- old docs conflict with code
- Worker discovery would be needed
