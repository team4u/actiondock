# 文档契约索引

只把这里当作模板导航。生成具体文档时只读取需要的模板文件；没有证据的文档整篇跳过并写入报告，生成的文档不得保留占位符。

- `template-actiondock.md`：`ACTIONDOCK.md` 入口导航模板。
- `template-common.md`：代码、领域、开发、运维等通用主题文档模板。
- `template-flows.md`：业务流程索引、流程文档、业务规则和状态机模板。
- `template-data.md`：数据模型索引和数据表文档模板。
- `template-integrations.md`：外部依赖文档模板。
- `template-ops.md`：任务、补偿和运维操作模板。
- `template-diagnosis.md`：观测、诊断索引、runbook、SQL/日志排查手册模板。
- `template-agent.md`：Agent 指南和查询工具上下文模板。
- `template-reports.md`：初始化报告和更新报告模板。
