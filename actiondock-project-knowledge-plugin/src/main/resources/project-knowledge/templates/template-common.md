# 通用主题文档模板

## 通用主题文档

适用于 `docs/code/*.md`、`docs/domain/*.md`、`docs/dev/*.md`、`docs/ops/*.md` 等主题文档。

```markdown
# {topic}

## 这篇文档解决什么问题
{说明读者读完后能理解什么、能做什么。}

## 新人先读
- {path or symbol}: {为什么先读}

## 当前职责
{解释这个模块/领域/数据/配置当前负责什么。}

## 核心概念
{解释代码中反复出现的概念、术语、对象、状态或配置。}

## 关键代码路径
- {path or symbol}: {职责和阅读提示}

## 调用链或数据流
1. {入口}
2. {关键处理}
3. {数据读写或外部调用}
4. {输出或副作用}

## 边界与非职责
{说明它不负责什么、与哪些模块的边界在哪里。}

## 常见误解
- {容易误读的点}: {正确理解和证据}

## 相关文档
- {doc path}: {为什么相关}

## 证据与不确定性
- 证据: {path/symbol/config/table}
- 有限推断: {如有，说明依据}
- 不确定: {如有，说明缺少什么证据}
```
