# 代码合并请求自动化评审标准操作规程

本规程用于指导智能体使用独立的 github-tools 产物完成 GitHub 代码合并请求的自动化评审与反馈。

## 任务执行步骤

- 发现与检查合并请求详情：
  - 调用 `get-pr` 获取目标合并请求的标题、作者、详细描述及代码修改行数等统计数据。
- 执行自动化代码评审：
  - 调用 `review-pr` 对合并请求进行自动化体检与规范检查，涵盖变更规模、描述完整度与进行中状态标记等。
  - 检查返回的评审结论与具体改进建议。
- 发表评审意见：
  - 调用 `comment-pr` 将生成的评审摘要与建议发表到讨论区。
  - 注意：除非用户明确要求，切勿执行自动合并操作。
